# 🧹 Universal Data Sanitizer & Auditor

An automated, production-grade Python CLI pipeline designed to ingest raw, corrupted, or messy CSV files and output an analysis-ready dataset. Built to handle the unpredictable edge cases found in real-world client spreadsheets, demonstrated across three end-to-end portfolio case studies.

## 🚀 The Problem
Clients often export data from legacy systems with missing values, inconsistent date formats, disguised nulls (e.g., `"N/A"`, `"unknown"`, `"-"`), and mixed text/numeric data types. Manual cleaning is slow, error-prone, and threatens data integrity.

## 🛠️ The Solution
This CLI tool (`data_sanitizer.py`) applies a multi-layer defense to standardize data in seconds:
1. **Auto-Delimiter Detection:** Uses `csv.Sniffer` to automatically detect whether a file uses commas, semicolons, tabs, or pipes.
2. **Header Normalization:** Strips whitespace, lowercases, and replaces spaces with underscores.
3. **Duplicate Removal:** Drops 100% identical rows to prevent data bloat.
4. **Disguised Null Detection:** Scans text columns for fake nulls (`n/a`, `null`, `?`, `tbd`) and converts them to true `NaN` values.
5. **Smart Numeric Scrubbing:** Strips currency symbols (`$`, `₹`, `€`), commas, and unit suffixes (`GB`, `kg`, `lbs`) before safely converting them to floats using `errors='coerce'` to handle corrupt entries.
6. **Auto-Date Parsing:** Detects date columns and standardizes them to `datetime` objects.

## 📂 Portfolio Case Studies

### 1. Case Study 1: Cafe Sales Data Cleaning
- **Focus:** Cleaning noisy point-of-sale (POS) transactional spreadsheets with missing items, inconsistent pricing entries, and malformed dates.
- **Outcome:** Standardized sales records ready for product-level and peak-hour revenue analysis.

### 2. Case Study 2: Laptop Store Data Cleaning
- **Focus:** Scrubbing product catalog and sales data containing mixed unit suffixes (`GB`, `kg`, `lbs`), currency formatting, and duplicate entries.
- **Outcome:** Clean, structured dataset enabling accurate specification comparisons and pricing analysis.

### 3. Case Study 3: Real Estate Data Cleaning & Interactive Dashboard
- **Files:** `real_estate_cleaning.ipynb` & `real_estate_dashboard.html`
- **Focus:** Automated sanitization of Nashville real estate transaction records (`nashville-housing-data`), paired with a lightweight, dark-mode browser dashboard built with HTML, Tailwind CSS, PapaParse, and Chart.js.
- **Dashboard Highlights:**
  - **KPI Summary Cards:** Total Transactions, Total Sales Volume, and Average Sale Price.
  - **Interactive Filters:** Filter transactions dynamically by **Year** (`sale_date_dt`) and **Land Use** (`land_use`).
  - **Visualizations:** Monthly Sales Volume Over Time, Top 10 Cities by Transactions (`property_city`), and Transactions by Land Use (`land_use`).
- **How to View the Dashboard:** Download `real_estate_dashboard.html`, open it in any web browser, click **Upload Cleaned CSV**, and select the cleaned output generated by `real_estate_cleaning.ipynb`.
